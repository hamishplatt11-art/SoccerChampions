# Headliners: World Soccer 48

A 1v1 big-head football game that runs in the browser. No install needed.

**Play:** open the GitHub Pages link for this repository.

## Modes
- **Full World Cup** – pick any of 210 nations on a spinning globe, fight through your continent's real-format qualifiers, then the final draw and the 48-team finals.
- **World Cup 48** – jump straight into the 48-team tournament.
- **Quick Match** and **2 Players** (same keyboard).

## Controls
| | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | ← / → |
| Jump | W (tap for a short hop) | ↑ |
| Kick | Space | ↓ |
| Power shot | E | K |

Jump + kick under a high ball for a **bicycle kick**, land on your opponent's head to **bounce** over them, and pop the floating bubbles with the ball for **power-ups**. Phones and tablets get on-screen buttons.

Progress saves in your browser.

## Run it locally
Open a terminal in this folder and run `python3 -m http.server`, then visit http://localhost:8000 (opening `index.html` directly won't load the globe data).
